# FN Personalizados — Landing Page

Landing page (mockada, sem backend) para apresentação à dona da FN Personalizados — loja de mimos e lembranças personalizadas.

## Conteúdo

- Hero com colagem estilo mesa de trabalho e parallax por ponteiro
- Catálogo de produtos (cards estilo etiqueta de presente)
- "Como funciona" em 4 passos
- Estatísticas animadas (contador)
- Avaliações de clientes em carrossel
- Galeria
- Contato via WhatsApp (link `wa.me` com número placeholder — trocar antes de publicar)

## Rodando localmente

Basta abrir `index.html` no navegador, ou servir a pasta com qualquer servidor estático:

```bash
python3 -m http.server 8000
```

## Stack

HTML + CSS + JavaScript puro (sem frameworks nem build step). Fontes via Google Fonts (Caveat, Baloo 2, Quicksand).
